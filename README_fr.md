# openGym pour YunoHost

openGym est un suivi d'entraînements auto-hébergé (séances, exercices, données de performance) avec authentification par passkey/webauthn. Ce paquet l'exécute en natif : frontend statique (vite) + API Node, sans Docker.

**Version livrée :** voir manifest.toml

## Caractéristiques

- Frontend statique + API Node natifs (sans Docker)
- Authentification passkey (webauthn)
- Jeu de données d'exercices optionnel (images/GIF)
- Authentification unique YunoHost via le script contrib opengym-sso-link (facultatif)
