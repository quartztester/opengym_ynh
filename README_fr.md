# openGym pour YunoHost

openGym est un suivi d'entraînements et de poids du corps auto-hébergé, avec
authentification par passkey (webauthn). Ce paquet l'exécute en natif :
frontend statique servi par nginx + API Node en service systemd, sans Docker.

**Version livrée :** 1.3.10

## Caractéristiques

- Frontend statique + API Node natifs (sans Docker)
- Authentification par passkey ; les comptes vivent dans l'application
- Bibliothèque d'exercices avec démos animées (jeu de données ~350 MB,
  téléchargeable en option à l'installation)
